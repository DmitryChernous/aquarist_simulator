# Симулятор аквариумиста

План разработки игры. Документ организует работу по этапам и фиксирует журнал версий.

## Концепция

Экономический симулятор с элементами эко-симуляции. Игрок — владелец магазина аквариумистики: выставочный зал, разводня рыб и сервисные услуги.

Четыре игровых режима образуют **один общий геймплейный цикл**:

```
Закупка рыб → Обустройство аквариумов (условия) → Выставочный зал (покупатели)
                        ↑                                          ↓
                   Разводня (своё производство)              Доход → деньги
                        ↑                                          ↓
                  Сервис (обслуживание чужих аквариумов)   ←  Репутация/навык
```

### Режимы

1. **Выставочный зал** — покупатели приходят и выбирают рыбу. Нужно обустраивать помещение и повышать привлекательность.
2. **Обустройство аквариумов** — подбор рыб для аквариума по условиям (температура, жёсткость воды, растительность, объём) и дизайн, влияющий на привлекательность зала и продажи конкретных видов.
3. **Закупка / разводня** — экономика магазина: когда и какую рыбу купить для перепродажи, когда вложиться в собственную разводню, оптовые продажи.
4. **Сервис** — заработок на обустройстве и обслуживании аквариумов клиентов.

### Ключевая механика: совместимость

У каждого вида рыб есть требования (температура, жёсткость, растительность, минимальный объём). Несовпадение → стресс, болезни, снижение привлекательности и продаж. Логика совместимости прошита во все режимы.

## Технологии

- **Vite + TypeScript** — сборка, строгая типизация для растущей симуляции.
- **Canvas** — отрисовка сцены (аквариумы, рыбы-фигуры).
- **DOM** — интерфейс (панели, магазин, статистика).
- **localStorage** — сохранение прогресса.
- **GitHub Pages** — автодеплой при каждом push в `main`.

## Архитектура

```
src/
  data/        fish.ts      — каталог видов рыб (цена, требования по воде, объём)
               aquarium.ts  — модели аквариумов (габариты, объём), лимиты дизайна
               decor.ts     — декорации: растения, камни, коряги (поштучно)
               water.ts     — реестр параметров воды (15 параметров, кейжуал/хардкор)
               shop.ts      — оборудование (с настраиваемыми параметрами), стеллажи
  sim/         aquarium.ts  — аквариумы/склады, расчёт воды, рекалькуляция O₂/свет
               conditions.ts — совместимость условий воды и вида
               health.ts     — здоровье рыб, стресс, эффекты оборудования
               economy.ts    — деньги, покупка/продажа, ежедневное содержание
               buyers.ts     — покупатели, привлекательность зала/витрины
  ui/          render.ts    — отрисовка аквариума (canvas)
               panels.ts    — интерфейс: зал, аквариум, склад, магазин (DOM)
  main.ts      — игровой цикл, состояние, действия
  save.ts      — сохранение в localStorage (миграция v3 → v4)
  timing.ts    — игровое время, длительность дня
```

Симуляция отделена от рендера: игровая логика чистая (без DOM), тикает по игровому времени.

- [x] Глобальный рынок: спрос и цены на виды рыб меняются со временем

### Пошаговый режим
- [x] Внутри дня симуляция идёт в реальном времени (рыбы плавают, заказы истекают, посетители приходят), в HUD виден таймер текущего дня

### Игровое время
- [x] Время считается в днях, а не в секундах: день длится заданное реальное время (параметр `DAY_DURATION_SECONDS`, сейчас 120 c = 2 мин)
- [x] Дата в HUD: год / месяц / неделя / день (360 дней в году, 30 в месяце, 7 в неделе)
- [x] Прогресс-бар в верхней панели показывает, сколько прошло в текущем дне
- [x] По окончании длительности дня (таймер) день сменяется автоматически

### Управление временем
- [x] Пауза (кнопка ⏸/▶)
- [x] Ускорение времени ×2, ×3, ×5 — масштабирует всё внутридневное время (день, заказы, посетители, рыбы)

### Этап 1.7 — Выставочный зал: стеллажи, аквариумы, вода, оборудование, декор
- [x] Стеллажи как сущности: занимают место в зале, полки с габаритами (не любой аквариум помещается), грузоподъёмностью (лимит суммарного литража) и ценой
- [x] Аквариумы-витрины размещаются на полках стеллажей (`shelfId` + `slabId`)
- [x] Аквариум: габариты, объём, вода, декор, рыбы, оборудование, уровень дизайна
- [x] Вода: параметры `temperature / ph / gh` (редактируемые) + производные `o2` (аэрация) и `light` (освещение)

- [x] Декорации — поштучно (растения / камни / коряги), влияют на растительность и привлекательность
- [x] Реестр `WATER_PARAMS` на 15 параметров воды (nh3, no2, no3, po4, ph, gh, kh, cl, co2, o2, fe, k, ca, cu, mg) — расширяем под хардкор-режим
- [x] Стартовое состояние: 1 стеллаж на 2 полки + 1 аквариум
- [x] Миграция старых сохранений (v3) → v4: display-аквариумы на стеллаж, складские — в `storage`
- [x] Canvas-визуализация зала (стеллажи и аквариумы на них) как главная часть экрана
- [x] Навигация по функциональным доменам: 5 вкладок (Помещения · Аквариум · Склад · Магазин · Заказы)
- [x] Зал: визуализация + список стеллажей + панель переходов + пустые состояния с призывами к действию
- [x] Заказы покупателей — отдельный экран; магазин с двумя разделами «Для продажи» и «Обустройство» (стойки, оснащение, мебель, стеллаж-витрина)
- [ ] Редактирование стеллажа: перенос/расстановка аквариумов, добавление полок
