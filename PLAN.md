# Симулятор аквариумиста

План разработки игры. Документ организует работу по этапам и фиксирует журнал версий.

## Концепция

Экономический симулятор с элементами эко-симуляции. Игрок — владелец магазина аквариумистики: выставочный зал, разводня рыб и сервисные услуги.

Четыре игровых режима образуют **один общий геймплейный цикл**:

```
Закупка рыб → Обустройство аквариумов (условия) → Выставочный зал (покупатели)
                        ↑                                          ↓
                   Разводня (своё производство)              Доход → деньги
                        ↑                                          ↓
                  Сервис (обслуживание чужих аквариумов)   ←  Репутация/навык
```

### Режимы

1. **Выставочный зал** — покупатели приходят и выбирают рыбу. Нужно обустраивать помещение и повышать привлекательность.
2. **Обустройство аквариумов** — подбор рыб для аквариума по условиям (температура, жёсткость воды, растительность, объём) и дизайн, влияющий на привлекательность зала и продажи конкретных видов.
3. **Закупка / разводня** — экономика магазина: когда и какую рыбу купить для перепродажи, когда вложиться в собственную разводню, оптовые продажи.
4. **Сервис** — заработок на обустройстве и обслуживании аквариумов клиентов.

### Ключевая механика: совместимость

У каждого вида рыб есть требования (температура, жёсткость, растительность, минимальный объём). Несовпадение → стресс, болезни, снижение привлекательности и продаж. Логика совместимости прошита во все режимы.

## Технологии

- **Vite + TypeScript** — сборка, строгая типизация для растущей симуляции.
- **Canvas** — отрисовка сцены (аквариумы, рыбы-фигуры).
- **DOM** — интерфейс (панели, магазин, статистика).
- **localStorage** — сохранение прогресса.
- **GitHub Pages** — автодеплой при каждом push в `main`.

## Архитектура

```
src/
  data/        fish.ts      — каталог видов рыб (цена, требования, размер)
               aquarium.ts  — конфигурации аквариумов
  sim/         conditions.ts — совместимость вида и аквариума
               health.ts    — здоровье рыб, стресс
               economy.ts   — деньги, покупка/продажа
               buyers.ts    — покупатели, привлекательность зала
  ui/          render.ts    — отрисовка сцены
               panels.ts    — интерфейс магазина/аквариума
  main.ts      — игровой цикл, состояние
  save.ts      — сохранение в localStorage
```

Симуляция отделена от рендера: игровая логика чистая (без DOM), тикает по игровому времени.
